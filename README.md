# Amazon UK Market Intelligence & Dynamic Pricing Pipeline

An enterprise-grade, asynchronous web automation and data harvesting platform built to extract real-time e-commerce intelligence from the live Amazon UK marketplace.

## 🚀 Architectural Core Features
- **Independent Residential Routing Matrix:** Outfitted with automated network circuit tunneling (via local SOCKS5 gateway architectures) to seamlessly bypass aggressive anti-bot CDN firewalls and 503 service restrictions.
- **Elite Header Emulation Layer:** Spoofs standard browser tracking metrics down to the byte level, simulating standard Windows 10 / Firefox human interaction signatures.
- **Dynamic Structural Grid Handling:** Utilizes resilient CSS multi-container fallback selection arrays capable of harvesting text data rows from shifting e-commerce layouts.
- **Pristine Database Compilation:** Automatically quote-locks extracted text fields (`QUOTE_MINIMAL`) to isolate target strings and protect database column alignment from breaking due to structural item commas.

## 📊 Extracted Data Schema
The automated engine streams data sequentially page-by-page directly into a structured database core (`market_prices.csv`):
- `Timestamp`: Temporal tracking anchor (YYYY-MM-DD HH:MM:SS)
- `Product Name`: Cleaned textual string title of the marketplace listing
- `Price Tier`: Clean, localized transaction metrics forced natively into British Pounds (£)
- `Platform Link`: Direct source query path referencing the target inventory index
- `Status`: Functional execution baseline confirmation

## 🛠️ Technology Stack
- **Language:** Python 3.10+

- **Network Layer:** SOCKS5 Encrypted Proxy Tunneling / Tor Daemon Service Layer
- **Storage Engine:** Standard I/O CSV Database Engine
