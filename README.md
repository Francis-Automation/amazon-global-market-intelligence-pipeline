# Cross-Border Amazon US & UK Multi-Niche Market Intelligence Pipeline

An enterprise-grade, asynchronous web automation and data harvesting platform built to extract real-time competitor pricing matrices, inventory shifts, and promotional trends across high-growth retail sectors on the live Amazon United States (.com) and United Kingdom (.co.uk) marketplaces.

## 🎯 Core Market Focus
This pipeline is optimized to track high-volatility, high-demand e-commerce sectors requiring strict weekly pricing monitoring:
1. **Apparel & Fashion** (Clothing, Activewear, Footwear, Fashion Accessories)
2. **Health & Wellness** (Dietary Supplements, Vitamins, Sports Nutrition)
3. **Beauty & Personal Care** (Skincare Serums, Cosmetics, Luxury Grooming)

## 🚀 Architectural Core Features
- **Multi-Region Gateway Architecture:** Seamlessly shifts data tunnels between US and UK routing nodes using automated SOCKS5 residential proxy circuit configurations.
- **Independent Anti-Bot Bypass:** Outfitted with elite header emulation layers that spoof human browser signatures down to the byte level, completely clearing 503 firewalls and regional CDN blocks.
- **Dynamic Structural Grid Handling:** Utilizes resilient CSS multi-container fallback selection arrays capable of harvesting text data rows from shifting international e-commerce layouts.
- **Pristine Database Compilation:** Automatically quote-locks extracted text fields (`QUOTE_MINIMAL`) to isolate target strings and protect database column alignment from breaking due to structural item commas.

## 🗓️ Corporate Workflow & Retainer Cadence
This data pipeline is engineered for high-value weekly market intelligence operations:
1. **Sunday Evening Deep Sweeps (9:00 PM Local):** Deploys automated matrix tracking loops to harvest volatile weekend pricing changes across international sectors at peak volume hours.
2. **Monday Morning Reporting (7:00 AM Delivery):** Compiles and exports structured, quote-insulated CSV deliverables engineered for immediate injection into executive weekly strategy meetings.

## 📊 Extracted Data Schema
The automated engine streams data sequentially page-by-page directly into a structured database core (`market_prices.csv`):
- `Timestamp`: Temporal tracking anchor (YYYY-MM-DD HH:MM:SS)
- `Region / Marketplace`: Target indicator flag (US Market / UK Market)
- `Product Name`: Cleaned textual string title of the marketplace listing
- `Price Tier`: Clean, localized transaction metrics forced natively into Local Currencies ($ USD / £ GBP)
- `Platform Link`: Direct source query path referencing the target inventory index
- `Status`: Functional execution baseline confirmation
